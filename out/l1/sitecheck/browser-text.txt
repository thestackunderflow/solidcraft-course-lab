Platform & architecture On Windows, x64 is for most Intel and AMD PCs. ARM64 is for Windows on ARM. The x86 build supports 32-bit systems. The macOS Universal package includes Apple silicon and Intel builds. For Linux, choose x64 or ARM64 to match your processor, then select your preferred package format. Read the installation notes Packages & verification Use an installer or disk image for a standard desktop setup. Portable archives and Linux packages provide alternatives for your environment. Verify checksums against the upstream release. A matching checksum confirms the expected bytes; it does not establish a publisher signature. View release checksums on GitHub AUTOMATION & AGENTS Looking for the CLI? SolidCraft’s command line runs scripts, inspects designs, exports files, and exposes the local MCP server. The macOS CLI is a separate Universal ZIP listed above. For other platforms, follow the maintained installation instructions to find or build the right executable. Desktop package contents vary.
