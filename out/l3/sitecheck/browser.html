PACKAGE GUIDE

Choose a package.

Platform & architecture

On Windows, x64 is for most Intel and AMD PCs. ARM64 is for Windows on ARM. The x86 build supports 32-bit systems.

The macOS Universal package includes Apple silicon and Intel builds. For Linux, choose x64 or ARM64 to match your processor, then select your preferred package format.

Read the installation notes

Packages & verification

Use an installer or disk image for a standard desktop setup. Portable archives and Linux packages provide alternatives for your environment.

Verify checksums against the upstream release. A matching checksum confirms the expected bytes; it does not establish a publisher signature.

View release checksums on GitHub

AUTOMATION & AGENTS

Looking for the CLI?

SolidCraft’s command line runs scripts, inspects designs, exports files, and exposes the local MCP server.

The macOS CLI is a separate Universal ZIP listed above. For other platforms, follow the maintained installation instructions to find or build the right executable. Desktop package contents vary.

CLI & MCP setupMCP setup and tools
Code signing
Windows builds will be signed using SignPath. Free code signing provided by SignPath.io, certificate by SignPath Foundation. This is being set up, and current Windows builds are not signed yet. macOS builds are being set up for Apple Developer ID signing and notarization. Until then, verify downloads against the published checksums.
Before upgrading
Keep backups of your designs. File format and compatibility changes are listed in the v0.22.0release notes.
Development builds, Flatpak, and building from source

Nightly builds are available on GitHub Releases. They are kept separate from the latest stable release. Follow Getting started for source builds and the existing Flatpak feed.
